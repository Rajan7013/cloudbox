Getting started

On your phone.

How do I install CloudBox?

Download the Android APK above and open it on your phone. If Android asks, allow your browser or file manager to install this app, then confirm the installation.

Which Drive files can CloudBox open?

Sign in with Google and grant file access. CloudBox uses the drive.file permission for items you create or explicitly share with the app. Read the privacy policy.

Can I read files offline?

Choose “Make available offline” on a supported file while connected. Its saved copy is available on that device when your connection drops.
